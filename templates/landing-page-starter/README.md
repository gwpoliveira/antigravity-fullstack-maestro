# 🚀 Starter de Landing Page (High-Conversion & SEO 100/100)

Template oficial do **Antigravity Full Stack Maestro** para criação imediata de Landing Pages de altíssima conversão.

## ✨ Recursos Inclusos:
- **Design Obsidian & Dark Mode**: Cores profundas, micro-interações táteis e contrastes aprovados WCAG AA.
- **Hero Section com LCP Otimizado**: Carregamento instantâneo de imagem com `priority`.
- **Bento Grid Modular**: Exibição elegante de features e diferenciais.
- **Tabela de Preços com Toggle**: Alternador dinâmico Mensal / Anual (-20%).
- **FAQ com Rich Snippets**: Schema.org `FAQPage` (JSON-LD) para o Google exibir perguntas e respostas na busca.
- **Indexação Nativa**: `sitemap.ts` e `robots.ts` pré-configurados.

## 📦 Como Usar:
Copie os componentes da pasta `components/` para o seu projeto Next.js e monte sua página em `app/page.tsx`.
