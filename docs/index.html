🐧 Deploy em VPS Bare-Metal (100% Sem Docker)

Extraia 100% da performance do hardware sem consumo excessivo de RAM por contêineres.

Script de Deploy Zero-Downtime (/var/www/meu-app/deploy.sh) 
#!/bin/bash
set -e
echo ">>> Iniciando Atualização Zero-Downtime..."
git pull origin main

# Backend Django
source backend/venv/bin/activate
pip install -r backend/requirements.txt
python backend/manage.py migrate
python backend/manage.py collectstatic --noinput
sudo systemctl reload gunicorn

# Frontend Next.js
cd frontend
npm ci && npm run build
pm2 reload ecosystem.config.js --env production

echo ">>> Deploy Concluído com Sucesso!"
