4. Deploy em VPS Bare-Metal (100% Sem Docker)

A hospedagem direta no sistema operacional Linux (Ubuntu/Debian) elimina o consumo excessivo de memória RAM e a latência de contêineres, aproveitando 100% da CPU do servidor.

Topologia no Servidor:

Serviço Tecnologia Comunicação Papel
Web Server & SSL Nginx + Certbot Portas 80 / 443 Reverse Proxy, Cache Estático e Gzip
Backend API Gunicorn + Systemd /run/gunicorn.sock Daemon Django via Unix Socket de baixa latência
Frontend SSR PM2 + Node.js 127.0.0.1:3000 Cluster Next.js com restart automático
Fila Assíncrona Celery + Redis Localhost Disparo de e-mails, webhooks e relatórios
Banco de Dados MySQL 8.x Nativo 127.0.0.1:3306 InnoDB Buffer Pool calibrado + Backup diário cron

Script de Deploy Zero-Downtime:

#!/bin/bash
set -e
echo ">>> Iniciando Deploy Zero-Downtime..."
cd /var/www/meu-app
git pull origin main

# 1. Backend
source backend/venv/bin/activate
pip install -r backend/requirements.txt
python backend/manage.py migrate
python backend/manage.py collectstatic --noinput
sudo systemctl reload gunicorn

# 2. Frontend
cd frontend
npm ci && npm run build
pm2 reload ecosystem.config.js --env production

echo ">>> Deploy Concluído com Sucesso!"
